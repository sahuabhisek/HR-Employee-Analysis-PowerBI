# HR-Employee-Analysis-PowerBI# 📊 HR Employee Analysis Dashboard – Power BI

## 📌 Project Overview

This project focuses on analysing Human Resources (HR) employee data using Microsoft Power BI.

The main objective is to analyse employee attrition, workforce distribution, department-wise employee data, gender distribution, education field, marital status, and job roles through interactive dashboards.

## 🎯 Project Objectives

- Analyse total and active employees.
- Calculate employee attrition and attrition rate.
- Identify departments with higher employee attrition.
- Analyse gender-wise employee distribution.
- Understand employee distribution by education and marital status.
- Identify job roles with higher attrition.
- Present meaningful HR insights using Power BI visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization

## 🔍 Key Business Insights

- Total workforce consists of 1,470 employees.
- 237 employees have left the organization.
- Overall attrition rate is 16.12%.
- R&D department has the highest attrition with 133 employees.
- Sales Executive job role has the highest visible attrition count of 57.
- Average employee age is approximately 37 years.

## 💡 Business Recommendations

- Investigate employee attrition in the R&D department.
- Analyse employee satisfaction and retention in Sales roles.
- Review career development and employee engagement strategies.
- Monitor workforce distribution across different job roles.
